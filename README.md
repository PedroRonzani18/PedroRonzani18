## Featured Projects

### CodeLife Modernization — Undergraduate Thesis

Experimental modernization of a legacy educational platform using **NestJS, React and PostgreSQL**.

Beyond the application itself, I designed an AI-assisted engineering workflow based on:

- repository-level agent instructions;
- scoped and progressive context loading;
- specialized engineering skills;
- Architecture Decision Records (ADRs);
- explicit change contracts;
- separation between planning, implementation and validation;
- validation gates and traceable technical evidence.

The project explores how coding agents can be integrated into a controlled software engineering process instead of being used only for ad-hoc code generation.

[View repository](https://github.com/PedroRonzani18/codelife-migrado/)

### Swiss Kit Core

Reusable TypeScript monorepo built with **React/Vite, NestJS, Prisma/PostgreSQL and shared Zod contracts**.

Includes Google OAuth, HttpOnly cookie sessions, access control, automated testing, PostgreSQL integration tests, browser E2E tests, CI and deployment documentation.
